# TWRP Remote - published copy

The master copy of TWRP Remote lives in the strubedo vendor kit
(`vendor/strubedo/twrp_remote`, which also builds the phone-side
`twrp_remote` binary into the recovery, and from which `make_release.sh`
packages it, recording the kit commit). This folder is a synced copy of its
source - the PC app, its installers and the phone-side server - so this
repository carries it. Synced from kit commit
08ff6f6.
